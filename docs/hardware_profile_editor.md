# ハードウェア構成エディタ

## 目的

`設定` タブの `ハードウェア構成エディタ` で、`config/hardware_profile.yaml` をダッシュボードから編集できます。

このエディタは、配線計画と実機接続メモを残すためのものです。

## 重要な安全注意

保存しても実モータ出力は有効になりません。

次のファームウェア定数は、このUIから変更しません。

- `MOTOR_OUTPUT_ENABLED 0`
- `USE_REAL_IMU 0`
- `USE_REAL_LIDAR 0`

実センサやモータドライバを接続する前に、必ず安全ダミー状態で確認してください。

## 編集できる項目

ボード:
- ボード名
- FQBN
- COMポート
- 通信速度

IMU:
- 有効
- 型番
- 通信方式
- SDA pin
- SCL pin
- 電圧
- メモ

LiDAR:
- 有効
- 型番
- 通信方式
- UART RX/TX pin
- I2C SDA/SCL pin
- 電圧
- メモ

モータドライバ:
- 有効
- 型番
- left/right PWM pin
- left/right DIR pin
- STBY pin
- モータ電源
- ロジック電源
- メモ

エンコーダ:
- 有効
- left/right A/B pin
- pulses per rev
- メモ

アクチュエータ:
- 有効
- 種類
- メモ

## 保存時の確認

保存前に、ボーレートやピン番号が正しい形式か確認します。

モータドライバを有効にした場合は強い警告を表示します。ただし、保存しても `MOTOR_OUTPUT_ENABLED` は変更されません。

## プリセット

入力補助として、次のプリセットを用意しています。

- すべてダミー
- MPU6050想定
- UART LiDAR想定
- TB6612FNG想定

プリセットは `hardware_profile.yaml` のメモを埋めるだけです。ファームウェア定数は変更しません。

## 実機クイック確認ログとの関係

実機クイック確認の保存結果には、最新のハードウェア構成サマリーが含まれます。

先生や班員に状態を共有する時は、ホームの `現在状態をコピー` も使えます。

## 配線表と接続チェックシート

`設定` タブの `配線表を作成` を押すと、現在の `hardware_profile.yaml` から配線表と接続チェックシートを自動生成します。

保存先:

```text
logs\wiring_reports\
```

保存形式:

- TXT
- JSON

作成後は、`配線表をコピー` で内容をクリップボードへコピーできます。

`配線表を開く` を押すと、最新のTXT形式の配線表を開きます。

配線表を作成しても、次の安全設定は変更されません。

- `MOTOR_OUTPUT_ENABLED 0`
- `USE_REAL_IMU 0`
- `USE_REAL_LIDAR 0`

## YAMLを直接編集する場合

`YAMLを開く` から `config/hardware_profile.yaml` を開けます。

直接編集した後は、ダッシュボードの `読み込み` を押して内容を再読み込みしてください。
