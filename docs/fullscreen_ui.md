# 全画面表示と大画面レイアウト

## 目的

全画面表示は、開発中のPC画面、プロジェクター、実機確認で状態を大きく見やすくするための表示です。

通常表示は、コードや資料を横に置きながら使うコンパクトな開発用表示です。

## 切り替え方法

- `F11`: 全画面表示と通常表示を切り替え
- ヘッダーの `全画面表示`: 全画面へ切り替え
- ヘッダーの `通常表示に戻す`: 通常表示へ戻す

`Esc` は従来どおり緊急停止です。全画面解除には使いません。

## ヘッダー

全画面でもヘッダーは表示されます。

ヘッダーには次を表示します。

- 現在モード
- 安全状態
- ESP32接続状態
- 現在指令
- 表示モード
- 緊急停止ボタン

## タブごとの見方

ホーム:
- 次にやることを大きく表示
- 今日の作業ナビをカード表示
- ESP32、ファームウェア、IMU、LiDAR、モータ、実機確認、配線表を一覧表示

実機接続:
- ESP32状態、実機クイック確認、安全チェックリストを横並びに近い形で表示
- 実機クイック確認ボタンを見つけやすく配置

センサ:
- 概要、IMU、LiDAR、エンコーダ、カメラをサブタブで表示
- 値は大きめのカード表示

駆動:
- 安全ダミーモードを明示
- 現在指令、走行操作、モータ状態を分離

シミュレーション:
- 仮想フィールドを大きく表示
- 右側に制御と状態を配置

ログ:
- ESP32受信ログは等幅フォント
- 検索欄で `STATUS`、`IMU`、`LiDAR`、`MOTOR`、`DRIVE`、`FW`、`ERROR` を絞り込み可能

設定:
- ハードウェア構成、配線表、エディタをスクロールしながら確認

診断:
- ESP32通信テストとArduino CLI書き込み操作を縦に整理

ドキュメント:
- 資料をカテゴリ別に表示

## プロジェクターで使う時

1. `F11` で全画面表示にします。
2. `ホーム` で全体状況を見せます。
3. 実機確認時は `実機接続` を開きます。
4. ログを見せる時は `ログ` を開きます。
5. 緊急停止ボタンが常に上部にあることを確認してください。

## フォント警告対策

起動確認で `QFont::setPointSize` 警告が出る環境があったため、アプリ起動時に安全なフォントサイズを明示しています。

`pc/main_ui.py` と `pc/widgets` では `setPointSize` に 0 以下の値を直接渡さないようにし、Qt内部から出る該当警告だけを抑制しています。

F11全画面表示、Esc緊急停止、実機操作前チェックカード、安全設定の値は変更していません。
