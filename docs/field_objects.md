# フィールドオブジェクト

## 目的

テストフィールド上に、走行確認やセンサ確認で使う配置物をmm座標で管理します。

## 定義場所

フィールドオブジェクトは次のYAMLに定義します。

```text
config/field/f3rc2026_field.yaml
```

`objects` に、名前、表示名、矩形、色、根拠メモを追加します。

```yaml
objects:
  - name: sample_object_a
    label_ja: 配置確認オブジェクトA
    rect: {x_mm: 2650, y_mm: 1050, width_mm: 180, height_mm: 180}
    color: "#facc15"
    kind: "generic"
    source_note: "暫定。公式図面または実測で要確認"
```

標準では次の種類を使えます。

- 黒レンガ: `black_brick`
- 白レンガ: `white_brick`
- じょうろ: `watering_can`
- 確認オブジェクト: `generic`

## テストフィールドでの扱い

`テストフィールド` タブの右側に `オブジェクト編集` 欄があります。

- `オブジェクト表示`: オブジェクトの表示ON/OFF
- `オブジェクト編集モード`: フィールド上で選択、追加、移動、削除できます
- `追加する物`: 黒レンガ、白レンガ、じょうろなどを選びます
- フィールド上をクリック: 既存オブジェクトなら選択、空き場所なら選択中の種類を追加
- フィールド上でドラッグ: 選択したオブジェクトをそのまま移動
- `マウス位置に追加`: マウス座標に選択中の種類を追加
- `中央に追加`: フィールド中央に選択中の種類を追加
- `選択を複製`: 選択中のオブジェクトを近くに複製
- `選択削除`: 選択中のオブジェクトを削除
- `X` / `Y` / `座標反映`: 選択中のオブジェクトの左上座標を直接指定
- `移動量`: 10 / 50 / 100 / 500 mm から選択
- `上へ` / `下へ` / `左へ` / `右へ`: 選択中のオブジェクトを指定した移動量で移動
- `オブジェクト配置リセット`: YAML定義の配置へ戻す
- `全体リセット`: R1/R2、軌跡、オブジェクト、センサ表示を初期状態へ戻す

現時点では、公式図面または実測で確定していない配置は暫定値として扱います。
