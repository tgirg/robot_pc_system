# F3RC2026公式フィールドmm座標モデル

## 目的

FC用ダッシュボードの「テストフィールド」タブで、F3RC2026公式フィールド図面をもとにしたmm座標モデルを表示します。

R2の自己位置推定、LiDAR、光学式オドメトリ、エンコーダ確認で、実測値と公式フィールド上の期待値を比較できるようにするための土台です。

## 座標系

- 原点: フィールド左上
- X: 右方向を正、`0 ～ 4500 mm`
- Y: 下方向を正、`0 ～ 2400 mm`
- 形状管理: すべてmm
- 画面表示: 描画時だけpxへ変換

## 公式寸法

- フィールド全体: `4500 mm × 2400 mm`
- 木材: `幅 38 mm × 高さ 89 mm`
- 赤/青/白ライン: `幅 19 mm`
- 倉庫Bゾーンの橙ライン: `幅 38 mm`
- 寸法公差: `±5%`
- 床面: 緑色ロンリウム

## 定義ファイル

フィールド定義は次にあります。

```text
config/field/f3rc2026_field.yaml
```

このYAMLには、フィールド全体、木材、ライン、ゾーン、壁をmm座標で定義しています。

## ゾーン定義

現在のモデルでは次のゾーンを定義しています。

- 倉庫Aゾーン
- 倉庫Bゾーン
- 倉庫Cゾーン
- 遊歩道ゾーン
- 庭ゾーン
- R1スタートゾーン
- R2スタートゾーン
- フィールド外

内側パーティションや倉庫Bの棚寸法は公式図面から読み取った暫定値です。各要素の `source_note` に「公式図面から読み取り。要実測確認」と記録しています。

## テストフィールドタブの使い方

1. `python pc/main_ui.py` でダッシュボードを起動します。
2. `テストフィールド` タブを開きます。
3. 表示モードを `公式フィールド表示` にします。
4. 必要に応じて以下を切り替えます。

- グリッドON/OFF
- ゾーン名ON/OFF
- 壁/木枠ON/OFF
- ラインON/OFF
- ロボット軌跡ON/OFF
- LiDARレイON/OFF
- マウス座標表示

## オブジェクト編集

右側の `オブジェクト編集` 欄で、黒レンガ、白レンガ、じょうろ、確認オブジェクトをテストフィールド上に配置できます。

- `オブジェクト編集モード` をONにすると、フィールドクリックで選択または追加できます。
- フィールド上のオブジェクトをドラッグすると、そのまま移動できます。
- `追加する物` で種類を選び、空き場所クリック、`マウス位置に追加`、`中央に追加` で追加します。
- 選択中のオブジェクトは複製、削除、X/Y座標指定、移動量指定で調整できます。
- `オブジェクト配置リセット` で `config/field/f3rc2026_field.yaml` の初期配置に戻します。

## 寸法公差の注意

公式ルールでは図中寸法に±5%の寸法差があり得ます。

自己位置推定やLiDAR比較で数十mm以上の差が出る場合、センサ誤差だけでなく、実フィールドの施工誤差や木材位置のずれも確認してください。

## 実測値で補正する方法

実フィールドを測ったら、`config/field/f3rc2026_field.yaml` の該当値を更新します。

例:

- 外枠内寸
- 倉庫B棚の仕切り位置
- R2スタートゾーンの位置
- 庭ゾーン境界
- 木材の実際の取り付け位置

変更後は `examples/test_field_model.py` を実行し、フィールドサイズやゾーン判定が崩れていないことを確認します。

## LiDAR/オドメトリとの関係

`pc/field/field_model.py` には将来連携用の関数があります。

- `simulate_lidar_from_field(x_mm, y_mm, theta_deg)`
- `raycast_to_walls(x_mm, y_mm, angle_deg)`
- `get_expected_wall_distance(front/left/right)`

これにより、実LiDAR値と公式フィールド上の期待壁距離を比較できます。

現時点では安全のため、実モータ出力やESP32への自動アップロードは行いません。

## R1/R2表示

通常の位置確認用に、フィールド上へR1/R2を表示します。

- R1初期位置: `X 2100 mm / Y 300 mm / θ 0 deg`
- R2初期位置: `X 2100 mm / Y 2100 mm / θ 0 deg`（R2スタートライン枠内）
- R1は参照ロボット
- R2は現在位置、進行方向、スタートからの移動量、軌跡を表示

初期位置は `config/field/f3rc2026_field.yaml` の `robots` で管理しています。`source_note` に「公式図面から読み取り。要実測確認」と記録しています。

## センサ未接続時の表示

通常表示では、未接続の値が実センサ値のように見えないことを優先します。

- 未接続: 0
- 未受信: 0
- ERROR: 0
- DUMMY: 状態はDUMMY表示、通常値は0
- LiDAR: `LIDAR_STATUS,OK` のときだけ距離を表示
