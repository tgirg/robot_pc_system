# UI機能分割メモ

## 新しいタブ構成

ダッシュボードは、目的ごとに小さなページへ分けました。

- ホーム: 全体状況の確認
- 実機接続: ESP32接続、実機クイック確認、接続前チェックリスト
- センサ: IMU、LiDAR、エンコーダ、カメラの確認
- 駆動: 走行指令、停止、緊急停止、モータ出力状態
- テストフィールド: 位置、向き、軌跡、移動距離、表示倍率を確認
- シミュレーション: 仮想フィールド、仮想LiDAR、自動走行、リセット
- ログ: ESP32受信ログ、操作ログ、診断ログ、実機確認結果
- 設定: ハードウェア構成、ローカル設定、結果フォルダ
- 診断: 環境診断、COMポート確認、カメラ確認、ESP32通信テスト
- ドキュメント: 関連資料を開くためのリンク集

## 各タブの目的

ホームは、細かい値を詰め込まずに「今どういう状態か」だけを見る画面です。
`次にやること` と `今日の作業ナビ` で、ESP32接続、ボード一覧更新、コンパイル、書き込み、再接続、実機クイック確認、結果保存の順番を確認できます。
全画面表示では、ホームのカードと作業ナビを大きく表示します。

実機接続タブは、ESP32を接続して最初の通信確認を行う場所です。実機クイック確認では、受信、テスト送信、STOP送信、結果保存をまとめて確認できます。

センサタブは、センサ値だけを見る場所です。概要、IMU、LiDAR、エンコーダ、カメラをサブタブで分けています。

駆動タブは、走行操作とモータ出力状態を見る場所です。モータ出力は既定で無効（安全ダミー）です。

シミュレーションタブは、実機なしで走行指令、仮想フィールド、障害物、仮想LiDAR、自動走行を確認する場所です。

ログタブは、ESP32受信ログ、操作ログ、診断ログ、実機確認結果を分けて見る場所です。

設定タブは、ハードウェア構成やプロジェクト配置を確認する場所です。診断操作とは分けています。

診断タブは、PC環境、COMポート、カメラ、ESP32通信、ESP32スケッチ書き込み、センサテストスケッチ確認を行う場所です。

ドキュメントタブは、現在の状態まとめ、実装ロードマップ、ミニPC移行手順などを開く場所です。

## 実機確認時の流れ

1. 診断タブでCOMポートを更新します。
2. ESP32候補を自動選択します。
3. ESP32接続を押します。
4. 接続テストまたは受信確認を押します。
5. 実機接続タブで実機クイック確認を実行します。
6. ログタブで結果を確認し、必要ならコピーします。

## センサ確認時の流れ

1. センサタブを開きます。
2. センサ概要で接続状態とデータ種別を確認します。
3. IMU、LiDAR、エンコーダ、カメラのサブタブで詳細値を確認します。
4. Mock、シミュレーション、ESP32ダミー、実データを混同しないようにデータ種別を確認します。

ESP32側のセンサ出力形式を確認する場合は、診断タブの `ESP32書き込み` で `センサテスト近道` から目的のスケッチを選び、コンパイル、書き込み、シリアルモニタ確認を行います。
詳しくは `docs/sensor_test_sketches.md` を参照してください。

## 駆動確認時の流れ

1. 駆動タブを開きます。
2. 現在指令とモータ出力状態を確認します。
3. 前進、停止、左旋回、右旋回を必要に応じて押します。
4. 危険を感じたら緊急停止を押します。Escキーでも緊急停止できます。

## シミュレーション時の流れ

1. シミュレーションタブを開きます。
2. 仮想フィールド上のロボット位置を確認します。
3. 走行操作で仮想ロボットを動かします。
4. 必要ならシミュレーションリセット、初期位置に戻す、軌跡クリアを使います。
5. 自動走行を試す場合は、自動走行開始と自動走行停止を使います。

## ログ確認時の流れ

1. ログタブを開きます。
2. ESP32受信ログ、操作ログ、診断ログ、実機確認結果を切り替えます。
3. 必要ならクリップボードへコピーします。
4. 実機確認結果は結果フォルダから保存ファイルを確認できます。

## テストフィールドタブ

テストフィールドタブはFC用のフィールド確認画面です。

- F3RC2026公式寸法モデルを表示
- mm座標、左上原点で管理
- ゾーン判定、最近傍壁距離、表示倍率を表示
- LiDARレイとオドメトリ軌跡の表示準備

4カメラ合成など別プロジェクトの機能はこのタブに混ぜません。
## 書き込みタブ

`書き込み` タブでは、ESP32スケッチの選択、編集、検証、書き込みを行います。

- スケッチ選択
- コード表示と編集
- Ctrl+S保存
- `✓ 検証`
- `→ 書き込み`
- 出力ログ

シリアル出力確認は別の `シリアル` タブで行います。

既存の `診断` タブは維持し、詳細診断や従来の書き込み画面として残します。
