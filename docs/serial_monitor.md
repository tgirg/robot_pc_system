# アプリ内シリアルモニタ

## 目的

アプリ内シリアルモニタは、ESP32から出る生のSerial出力をそのまま確認するための画面です。`STATUS,OK` や `IMU,...` のような既存パーサ形式でなくても表示できます。

## Arduino IDEのシリアルモニタとの違い

Arduino IDEを開かず、ダッシュボード内でCOMポートを開いて受信できます。ファームウェア編集、コンパイル、書き込み後の確認を同じアプリ内で続けられます。

## COMポートの選び方

ESP32をUSB接続し、`COM更新` を押します。表示されたCOMポートからESP32のポートを選び、`接続` を押します。
接続中はボタンと状態ラベルが変わり、成功または失敗が表示されます。

実機接続タブや通常ESP32接続が同じCOMポートを使っている場合、同時には開けません。シリアルモニタを使う前に通常接続を切断してください。

## ボーレートの選び方

ESP32コードの `Serial.begin(...)` と同じ値を選びます。I2Cスキャナテンプレートや通常のdrive_controllerは `115200` を使います。

## I2Cスキャナ確認手順

1. `書き込み` タブで `imu_9axis_test` を選びます。
2. コンパイルします。
3. 既存のESP32書き込み画面から手動で書き込みます。
4. `シリアル` タブを `115200 bps` で接続します。
5. `I2C device found at 0x68` などの表示を確認します。

Arduino IDEで認識できている場合は、同じ確認内容を `esp32/imu_9axis_test/imu_9axis_test.ino` へ反映して、アプリからコンパイルと書き込みを試せます。

`接続時にESP32をリセット` をオンにすると、Arduino IDEのシリアルモニタのように接続直後の起動ログを取り直せます。手動で取り直したい場合は `ESP32リセット` を押します。
リセット中とログ保存中は進行バーが表示されます。

## 9軸IMU確認で見る値

多くの9軸IMUでは `0x68`、`0x69`、`0x28` などのI2Cアドレスが候補になります。実際のアドレスはモジュールや配線、AD0/SA0ピン設定で変わります。

シリアルモニタには `9軸IMUテスト成功例` と、検出状態の表示があります。

- `I2C認識: OK（0x68）`: I2Cスキャンでアドレスを検出しています。
- `IMU状態: OK`: `IMU_STATUS,OK` を受信しています。
- `IMU状態: ERROR`: `IMU_STATUS,ERROR` を受信しています。
- `ファームウェア`: `FW,<name>,<version>` を表示します。
- `LiDAR状態`、`エンコーダ状態`、`オドメトリ状態`、`距離センサ状態`、`ライン状態`、`カラー状態`: 各センサテストスケッチの `*_STATUS` を表示します。

書き込み画面の `シリアルで確認` を押すと、`シリアル` タブにCOMポートと `115200 bps` が設定されます。その後、手動で `接続` を押してください。
各種センサテストスケッチの出力例は `docs/sensor_test_sketches.md` を参照してください。

## ログ保存先

`ログ保存` を押すと、次の場所に保存します。

```text
logs/serial_monitor/
```

最新ログは次にもコピーされます。

```text
logs/serial_monitor/latest_serial_monitor.txt
```

## COMポート競合の注意

Windowsでは同じCOMポートを複数のプログラムが同時に開けません。Arduino IDEのシリアルモニタ、通常の実機接続、アプリ内シリアルモニタは同じCOMを同時使用できません。

## 実機接続タブと同時に使えない理由

実機接続タブはESP32のdrive_controller出力を読み、走行コマンドを送るためにCOMポートを開きます。シリアルモニタも同じCOMを直接開くため、同時使用すると競合します。

## コマンド送信時の注意

送信欄から任意の文字列をESP32へ送れます。モータ接続時は `DRIVE VEL 50 50` などのコマンドに注意してください。現在は送信をブロックしません。
