# 書き込みタブ

## 目的

`書き込み` タブは、ESP32用スケッチを確認・編集・検証・書き込みするための画面です。

既存の `診断` タブのESP32書き込み機能は残したまま、センサ確認やファームウェア確認で使いやすい入口として追加しています。

## 基本操作

1. `書き込み` タブを開く
2. スケッチを選択する
3. 書き込み先のCOMポートを選択する。COM10が見つかった場合は優先選択されます
4. コードを確認または編集する
5. `✓ 検証` を押してコンパイルする
6. `→ 書き込み` を押す
7. 確認ダイアログで内容を確認してから書き込む
8. 書き込み完了後、`シリアルで確認` を押して `シリアル` タブで出力を確認する

## スケッチ選択

選択できるスケッチは以下です。

- `drive_controller`
- `imu_9axis_test`
- `lidar_uart_test`
- `encoder_test`
- `optical_odometry_test`
- `distance_sensor_test`
- `line_color_sensor_test`
- `serial_echo_test`
- `all_sensor_dummy_test`

初期値は `drive_controller` です。

## ボードとFQBN

標準設定は以下です。

- ボード: `ESP32 Dev Module`
- FQBN: `esp32:esp32:esp32`

通常は変更不要です。画面では `詳細設定` を開いたときだけ表示します。

## 検証ボタン

`✓ 検証` は現在のスケッチを保存してから `arduino-cli compile` を実行します。

失敗した場合は下部の出力ログにエラーが表示されます。

## 書き込みボタン

`→ 書き込み` は、まず保存とコンパイルを行います。

コンパイル成功後に `ESP32へ書き込みますか？` という確認ダイアログを表示します。確認した場合だけESP32へ書き込みます。

アプリ起動時に自動で書き込むことはありません。

## シリアルモニタ

シリアル出力は別の `シリアル` タブで確認します。

- COMポートを選択
- ボーレートを選択
- `接続` を押す
- 必要に応じて `ESP32リセット` を押す
- 送信欄から文字列を送信できる

9軸IMUテストでは `115200` bpsを使います。

## 9軸IMU確認

`imu_9axis_test` を選択し、検証と書き込みを行います。

書き込み後に `シリアル` タブを `115200` bpsで接続し、以下のような出力を確認します。

```text
BOOT,IMU_9AXIS_TEST_READY
I2C scan start
I2C device found at 0x68
IMU_STATUS,OK
IMU,...
GYRO,...
STATUS,OK
```

`0x68`、`0x69`、`0x28` のいずれかが表示されればI2Cデバイスを認識しています。

## COMポート競合

同じCOMポートは同時に1つの画面からしか開けません。

以下が開いている場合は、先に切断してください。

- Arduino IDEのシリアルモニタ
- シリアルタブ
- 実機接続

## 安全設定

書き込みタブでは以下を明示しています。

- 実モータ出力: 無効
- `MOTOR_OUTPUT_ENABLED: 0`
- 自動アップロード: 無効
- 書き込みは確認後のみ

`drive_controller` を編集する場合も、実モータ出力は有効化しないでください。

## Arduino IDEとの違い

Arduino IDEと同じように、コードを見て、検証して、書き込んで、シリアル出力を確認できます。

一方で、このアプリではFCダッシュボード内で使うため、COM競合警告、確認付き書き込み、安全状態表示、ログ保存を追加しています。
