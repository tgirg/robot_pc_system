# 初心者向け 作業ガイド

## アプリを起動したら最初に見る場所

まず `ホーム` タブを見ます。

`次にやること` と `今日の作業ナビ` に、今押すべきボタンの順番が表示されます。
ロボットの移動量を見たい場合は、ホームの `テストフィールドを見る` または `テストフィールド` タブを開きます。

## ESP32を書き込む流れ

1. ESP32をUSBでPCへ接続します。
2. `診断` タブを開きます。
3. `ボード一覧更新` を押します。
4. `Arduino CLI確認` を押します。
5. `コンパイル確認` を押します。
6. 書き込みが必要な時だけ、`安全確認しました` にチェックします。
7. `ESP32へ書き込み` を押します。
8. 確認ダイアログで承認します。

書き込みは自動では行われません。必ずユーザーがボタンを押した時だけ実行されます。
実行中はボタン表示と状態ラベルが変わり、成功または失敗が画面上に残ります。

## 書き込み後の再接続

書き込みが成功したら、`実機接続` タブへ移動します。

そこで次を実行します。

1. `COMポート更新`
2. `ESP32候補を自動選択`
3. `ESP32接続`
4. `接続テスト`

ESP32から `FW,drive_controller,0.1.0` が受信できると、ホームと実機接続画面にファームウェア情報が表示されます。

## 実機クイック確認の流れ

`実機接続` タブで `実機クイック確認を実行` を押します。
実行中は各項目が `確認中`、`OK`、`失敗` に切り替わります。

この確認では、次をまとめて確認します。

- ESP32接続
- STATUS受信
- IMU受信
- LiDAR受信
- エンコーダ受信
- モータダミー受信
- テスト送信
- STOP送信

結果は `logs\hardware_checks` に保存されます。

## 結果保存の見方

`ログ` タブの `実機確認結果` で確認します。

- 最新結果を開く
- 最新結果をコピー
- 結果フォルダを開く

報告するときは、ホームの `現在状態をコピー` も便利です。

## つながらない時の確認

- Arduino IDEのシリアルモニタを閉じる
- アプリを複数起動していないか確認する
- ESP32を挿し直す
- USBケーブルを変える
- `COMポート更新` を押す
- `ボード一覧更新` を押す
- COM番号が変わっていないか確認する
- それでもだめなら `examples\quick_hardware_check.py COM10` を実行する

## 安全ダミーモードの意味

現在は安全のため、次の設定を維持しています。

- `MOTOR_OUTPUT_ENABLED 0`
- `USE_REAL_IMU 0`
- `USE_REAL_LIDAR 0`

つまり、ESP32へ走行指令を送っても、既定では実モータPWM出力は行いません。

## ショートカット

- `Esc`: 緊急停止
- `F5`: COMポート更新
- `Ctrl+H`: ホームへ移動
- `Ctrl+L`: ログへ移動
- `Ctrl+E`: 実機接続へ移動
- `F11`: 全画面表示を切り替え
## テストフィールド確認の流れ

通常の確認では次の順で見ると状態を追いやすくなります。

1. ホームで接続状態とセンサ状態を確認
2. 書き込みタブまたは診断タブでファームウェア選択と安全設定を確認
3. テストフィールドでR1/R2位置、移動量、センサ状態、フィールド寸法を確認

テストフィールドではR1/R2、R2スタート位置、移動量、センサ未接続状態、フィールド寸法が右側にまとまります。LiDAR未接続時は距離が0 mmになり、DUMMY値は実値として表示しません。
## 書き込みタブ

センサ確認では、`書き込み` タブを使うと操作が分かりやすくなります。

- 上部に `✓ 検証` と `→ 書き込み`
- 中央にスケッチコード
- 下部に黒背景の出力ログ
- シリアル確認は別の `シリアル` タブ
- COM10を優先選択
- 書き込みは確認ダイアログ後のみ

9軸IMU確認では `imu_9axis_test` を選び、書き込み後にシリアルモニタを115200 bpsで接続します。
