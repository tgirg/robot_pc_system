# テストフィールドタブ

## 目的

テストフィールドタブは、ロボットがフィールド上でどのくらい移動したかを確認するための画面です。シミュレーションデータを使って、ロボットの現在位置、向き、軌跡、移動距離を表示します。

## どのくらい動いたかを見る方法

1. ダッシュボードを起動します。
2. `テストフィールド` タブを開きます。
3. シミュレーションまたはMockデータでロボット位置が更新されると、フィールド上に現在位置と軌跡が表示されます。
4. 右側の `移動距離` 欄で、数値と単位を確認します。

## 現在位置の意味

`現在位置 X` と `現在位置 Y` は、フィールド中心を基準にしたロボット位置です。単位は内部的には `mm` で保持されます。表示単位は `mm`、`cm`、`m` から選べます。

## 開始地点からの距離

開始地点から現在位置までの直線距離です。

```text
sqrt((x - start_x)^2 + (y - start_y)^2)
```

`開始位置を現在位置に設定` を押すと、この距離は0から再計算されます。

## 累積移動距離

更新ごとの移動量を足し合わせた距離です。曲がりながら走った場合は、開始地点からの直線距離より大きくなります。

急に2000 mmを超える位置変化が出た場合は、位置ジャンプの可能性として累積距離に加算しません。

## 表示倍率

表示倍率は描画だけを変更します。実際の距離値は変わりません。

- `自動フィット`: フィールド全体が見えるように自動調整
- `25%`、`50%`、`100%`、`150%`、`200%`: 固定倍率
- `+`、`-`: 表示倍率を段階的に変更
- `表示をリセット`: 自動フィットへ戻す

## mm / cm / m の違い

- `mm`: ミリメートル。細かい移動確認に使います。
- `cm`: センチメートル。試験走行の読み取りに便利です。
- `m`: メートル。大きな移動量の確認に使います。

詳細表示では、主表示の単位に関係なく `mm / cm / m` を併記します。

## シミュレーションデータと実機データの違い

実機データは `OK`、新規受信、値が有効な場合だけ反映します。Mock、Simulation、未接続、ERROR、古い受信値は実データとして扱わず、R2位置を勝手に動かしません。

## 実機オドメトリ接続

光学式オドメトリは `OPTICAL_STATUS,OK` と `OPTICAL,dx,dy` を受信したとき、`config/optical_odometry.yaml` のスケール、反転、軸入れ替え、デッドバンド設定を通してR2位置へ反映します。詳しくは `docs/optical_odometry_field_integration.md` を参照してください。
