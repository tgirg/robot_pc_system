# 自動走行

## 目的
自動走行は、実機でモータを動かす前に、PC中心の制御判断をシミュレーション上で確認するための機能です。現在はルールベースの簡易制御だけを実装しています。

## 現在の対象
自動走行はシミュレーションモード専用です。Mockモードや実機モードでは開始できません。

## 判断方法
仮想LiDARの前方、左、右の距離を使って判断します。

- 前方距離が十分にある場合: 前進
- 前方が近い場合: 左右の空きが大きい方向へ旋回
- 左右も狭い場合: 停止
- LiDARデータがない場合: 停止

## 設定
`pc/config.yaml` の `auto_drive` でしきい値と速度を設定します。

```yaml
auto_drive:
  enabled: false
  mode: "rule_based"
  forward_speed: 100
  turn_speed: 80
  front_stop_distance_mm: 400
  side_preference_margin_mm: 100
  command_interval_ms: 300
```

`enabled` は将来の設定用です。現在のUIでは自動開始せず、必ず手動で `自動走行開始` を押して開始します。

## 安全との関係
自動走行が作る指令も、手動ボタンと同じように Command Layer と Safety Layer を通ります。緊急停止が押された場合、自動走行はただちに停止し、速度指令を出しません。

## 将来の拡張
現在のルールベース制御は、あとで実機LiDAR、経路計画、強化学習コントローラに置き換えられる前提の小さな入口です。

## 自動走行と公式フィールドモデル

F3RC2026公式フィールドモデルでは、現在位置がどのゾーンにいるかを判定できます。

将来的な自動走行では次の情報を利用できます。

- 現在ゾーン
- 最近傍壁までの距離
- `raycast_to_walls()` による期待壁距離
- LiDAR実測値との差分

現時点では確認用の表示と関数準備のみです。ESP32への自動アップロードや実モータ出力の有効化は行いません。
