# 使い方

## 起動方法

通常は次を実行します。

```cmd
tools\run_dashboard.bat
```

初回だけ、先に次を実行してください。

```cmd
tools\setup_windows.bat
```

## 手動起動

batファイルを使わない場合:

```cmd
.venv\Scripts\python.exe pc\main_ui.py
```

## 画面の見方

- `メイン`: カメラ、仮想フィールド、状態確認、センサ値、ログ、走行操作を表示します。
- `アクチュエータ`: 将来の作業機構用です。現在は準備中です。
- `設定 / 診断`: 現在の設定、診断ボタン、診断結果、ログ操作を表示します。

画面上部には現在のモード、安全状態、現在の指令、緊急停止ボタンが常に表示されます。
また、直近の操作結果は `最新通知` に表示されます。

## 設定 / 診断タブ

診断ボタン:

- `環境診断を実行`: Pythonと必要ライブラリを確認します。
- `COMポート確認`: ESP32候補のCOMポートを表示します。
- `カメラ確認`: カメラindex 0から3を確認します。
- `全診断を実行`: 上記をまとめて実行します。

診断結果欄はコピーできます。

## 処理中表示

ESP32接続、接続テスト、Arduino CLI確認、コンパイル、書き込み、シリアルモニタ接続、ログ保存などは、押した直後に状態ラベルが変わります。
処理中はボタンが一時的に無効化され、完了後に成功または失敗が表示されます。
詳しくは `docs/loading_and_feedback.md` を参照してください。

COMポート確認後、ESP32のCOM番号がわかったら `pc\config.yaml` の次を変更します。

```yaml
serial:
  port: "COM10"
communication:
  usb:
    port: "COM10"
controllers:
  drive:
    port: "COM10"
```

変更後はダッシュボードを再起動してください。

## Mock / Simulation / Real

- Mock: 実機センサは未接続です。表示値はダミーデータです。
- Simulation: 仮想フィールド上の計算値です。
- Real: 接続されたセンサの実データです。

状態確認では `接続状態` と `データ種別` を分けて表示します。Mock値は実データと誤解しないように `Mock` と表示されます。

## 操作ボタン

- `前進`: `DRIVE VEL 100 100`
- `停止`: `DRIVE VEL 0 0`
- `左旋回`: `DRIVE VEL -80 80`
- `右旋回`: `DRIVE VEL 80 -80`
- `緊急停止`: `EMERGENCY_STOP`

Escキーでも緊急停止を実行できます。

## テストフィールド

`テストフィールド` タブでは、ロボットの現在位置、向き、移動軌跡、開始地点からの距離、累積移動距離を確認できます。表示倍率は `自動フィット`、`25%`、`50%`、`100%`、`150%`、`200%` から選べ、`+` と `-` でも調整できます。表示単位は `mm`、`cm`、`m` から選べます。詳しくは `docs/test_field.md` を参照してください。

## ログ

ログは画面右側のログパネルに表示されます。CSVログを開始すると `logs/` に保存されます。

ログやキャッシュを整理する場合:

```cmd
tools\clean_cache.bat
```

## COMポート確認

ESP32をUSB接続した状態で、UIの `設定 / 診断` タブから `COMポート確認` を押します。

コマンドで確認する場合:

```cmd
tools\list_ports.bat
```

## ESP32書き込み

Arduino CLIを使う場合:

```cmd
tools\setup_arduino_cli.bat
tools\check_arduino_cli.bat
tools\upload_esp32_drive.bat COM10
```

シリアル出力を確認する場合:

```cmd
tools\serial_monitor_esp32.bat COM10
```

Arduino IDEを使う場合は `esp32\drive_controller\drive_controller.ino` を開いて書き込みます。
## ESP32接続操作

`設定 / 診断` タブの `ESP32接続` セクションから、ダッシュボード上でCOMポートを選択して接続できます。

- `COMポート更新`: 現在PCから見えているCOMポートを取得します。
- `ESP32候補を自動選択`: CP210xやCH340などESP32らしいポートを選択します。
- `ESP32接続`: 選択したCOMポートでESP32へ接続します。
- `ESP32切断`: 接続中なら `DRIVE STOP` を送ってから切断します。
- `接続テスト`: `STATUS,OK` を受信できるか確認します。
- `受信確認`: 約2秒間の受信内容を `ESP32受信ログ` に表示します。
- `テスト送信`: `DRIVE VEL 50 50` を明示的にESP32へ送信し、その後 `DRIVE STOP` を送信します。
- `停止送信`: `DRIVE STOP` をESP32へ送信します。
- `設定に保存`: 選択したCOMポートを `pc\config.yaml` に保存します。

Arduino IDEや別のシリアルモニタが同じCOMポートを開いていると、ダッシュボードから接続できません。接続前に閉じてください。

## IMU / ジャイロ表示

ESP32から次の形式の行を受信すると、センサ値パネルに実データとして表示します。

```text
IMU,45.2,1.0,-0.5
GYRO,0.01,-0.03,0.20
ENC,698,703
STATUS,OK
```

データがない場合は `データなし` と表示します。Simulationモードでは従来通りシミュレーション値を優先します。

## 送信先の安全ルール

- Simulationモード: 走行指令はシミュレータへ送られ、ESP32へは送信されません。
- Mockモード: Mock通信として扱います。
- Realモード: 接続済みESP32へ送信します。
- `ESP32通信テスト` の `テスト送信` と `停止送信` は明示的な確認操作として、接続中ESP32へ送信します。

## 新しい画面構成

ダッシュボードは、開発中に見る場所を分けています。

- `実機確認`: 実機テスト時に最初に見るタブです。ESP32接続、IMU、LiDAR、エンコーダ、モータ出力、現在指令を大きなカードで確認します。
- `シミュレーション`: 実機へ通常走行指令を送らず、仮想フィールド上で走行、自動走行、障害物、仮想LiDARを確認します。
- `センサ詳細`: センサ値を細かく確認します。
- `ログ`: ESP32受信ログ、操作ログ、診断ログを確認します。ログ消去とクリップボードコピーができます。
- `設定 / 診断`: COMポート更新、ESP32接続、接続テスト、受信確認、テスト送信、停止送信、環境診断を行います。

## 実機データとダミーの見分け方

`実機確認` タブの各カードには `データ種別` が表示されます。

- `実データ`: 接続された実センサからの値です。
- `ESP32ダミー出力`: ESP32ファームウェアが接続確認用に出している固定値です。
- `Mockデータ`: PC側のMock値です。
- `シミュレーション`: 仮想フィールド上の計算値です。
- `データなし`: 受信できる値がありません。

実機接続確認中に `IMU状態：ESP32ダミー出力` や `LiDAR状態：ESP32ダミー出力` と表示される場合、それはセンサ実物の値ではありません。`MOTOR_DUMMY` を受信した場合、モータカードは `モータ出力：無効（安全ダミー）` として確認できます。

詳しくは `docs\ui_layout.md` を参照してください。

## デスクトップから起動する

最初にショートカットを作成します。

```cmd
tools\create_desktop_shortcut.bat
```

作成後、デスクトップの `ロボットPCダッシュボード` をダブルクリックして起動します。

起動しない場合は、次の順に確認してください。

```cmd
tools\check_startup.bat
tools\run_dashboard.bat
```

`.venv` が無い、または PySide6 などが見つからない場合は、次を実行してください。

```cmd
tools\setup_windows.bat
```

アイコンを変更したい場合は `assets\app_icon.ico` を置いてから、もう一度 `tools\create_desktop_shortcut.bat` を実行してください。

詳しくは `docs\desktop_app.md` を参照してください。

## 実機クイック確認

実機接続をまとめて確認する場合は、`実機確認` タブの `実機クイック確認を実行` を押します。

確認内容:

- ESP32接続
- STATUS受信
- IMU受信
- LiDAR受信
- エンコーダ受信
- モータダミー受信
- テスト送信
- STOP送信

この機能は明示的な実機ベンチ確認です。`DRIVE VEL 50 50` を送信しますが、現在のESP32ファームウェアではモータ出力が無効なので `MOTOR_DUMMY` を確認します。最後に必ず `DRIVE STOP` を送信します。

詳しくは `docs\hardware_quick_check.md` を参照してください。

## 実機確認結果の保存とコピー

実機クイック確認が完了すると、結果は `logs\hardware_checks\` に保存されます。

`実機確認` タブで使える操作:

- `結果フォルダを開く`: 保存先フォルダをエクスプローラーで開きます。
- `最新結果をコピー`: 最新のTXT結果をクリップボードへコピーします。

最後に使ったCOMポートは `config\local_settings.json` に保存され、次回起動時に優先して選択されます。COM番号が変わった場合は `COMポート更新` を押して選び直してください。

詳しくは `docs\hardware_check_logs.md` を参照してください。

## 実ハードウェア接続準備

実部品を接続する前に、`config\hardware_profile.yaml` へ型番、電圧、通信方式、ピン番号を記録します。

参考資料:

- `docs\real_lidar_templates.md`
- `docs\real_imu_templates.md`
- `docs\motor_driver_safety.md`
- `docs\encoder_connection.md`
- `docs\hardware_integration_roadmap.md`
- `docs\current_status_summary.md`

`実機確認` タブの `実機接続前チェックリスト` は、モータ出力を有効にする前の手動確認用です。チェック状態は保存しません。

`設定 / 診断` タブの `ハードウェア構成メモ` から、構成ファイル、ロードマップ、現在状態まとめを開けます。
# 目的別タブの使い方

画面は、ホーム、実機接続、センサ、駆動、シミュレーション、ログ、設定、診断、ドキュメントに分かれています。

実機確認では、まず診断タブでCOMポート更新、ESP32候補自動選択、ESP32接続、接続テストを行います。その後、実機接続タブで実機クイック確認を実行します。

センサ値を確認する場合はセンサタブを使います。Mock、シミュレーション、ESP32ダミー出力、実データの違いはデータ種別で確認してください。

走行操作は駆動タブにまとめています。緊急停止ボタンは画面上部にも常に表示されます。

詳しい画面構成は `docs/ui_feature_split.md` を参照してください。

## ESP32ファームウェアのコンパイル / 書き込み

`診断` タブの `ESP32書き込み` セクションを使います。

1. `Arduino CLI確認` を押します。
2. 必要に応じて `ボード一覧更新` を押します。
3. `FQBN` と `COMポート` を確認します。
4. まず `コンパイル確認` を押します。
5. 書き込みが必要な場合だけ、`安全確認しました` にチェックして `ESP32へ書き込み` を押します。

書き込み前に、Arduino IDEのシリアルモニタを閉じてください。書き込み後は `実機接続` タブからESP32へ再接続します。

## 作業順に迷った時

`ホーム` タブの `次にやること` と `今日の作業ナビ` を見てください。

初心者向けの詳しい流れは `docs/usability_guide.md` にまとめています。

## ハードウェア構成を編集する

`設定` タブの `ハードウェア構成エディタ` を使います。

LiDAR、IMU、モータドライバ、エンコーダ、アクチュエータの型番、通信方式、ピン番号、電圧メモを入力できます。

保存しても `MOTOR_OUTPUT_ENABLED`、`USE_REAL_IMU`、`USE_REAL_LIDAR` は変更されません。

詳しくは `docs/hardware_profile_editor.md` を参照してください。

## 配線表を作成する

`設定` タブで `配線表を作成` を押すと、ハードウェア構成から配線表と接続チェックシートを作成します。

保存先は `logs\wiring_reports\` です。TXT形式とJSON形式で保存されます。

`配線表をコピー` で共有用にコピーでき、`配線表を開く` で最新のTXTを開けます。

## 全画面表示

`F11` で全画面表示と通常表示を切り替えできます。

全画面でも上部ヘッダーと緊急停止ボタンは表示されます。詳しくは `docs/fullscreen_ui.md` を参照してください。

## ESP32プログラム編集

`診断` タブの `ESP32プログラム編集` で、ESP32ファームウェアを直接編集できます。`保存`、`名前を付けて保存`、`このコードをコンパイル`、`書き込み画面へ移動` を使います。書き込みは自動では行われません。詳しくは `docs/firmware_editor.md` を参照してください。

## シリアルモニタ

`シリアル` タブで、ESP32からの生ログを確認できます。I2Cスキャナテンプレートを書き込んだ後、115200 bpsで接続すると `I2C device found at 0x68` などを確認できます。詳しくは `docs/serial_monitor.md` を参照してください。

9軸IMU確認では、`書き込み` タブで `imu_9axis_test` を選び、コンパイルと手動書き込みを行います。その後、`シリアル` タブを115200 bpsで接続し、`0x68`、`0x69`、`0x28` などが表示されるか確認します。

より簡単に行う場合は、`ESP32書き込み` の `9軸IMUテストを書き込む` を押します。
一連の作業をまとめたい場合は `9軸IMUテストをコンパイルして書き込み` を押します。コンパイル成功後に確認ダイアログが出て、承認した場合だけ書き込みます。
書き込み後は `シリアルで確認` を押し、COMポートと115200 bpsが設定された状態で `接続` を押してください。

LiDAR、エンコーダ、光学式オドメトリ、距離センサ、ライン/カラーセンサ、シリアル通信、全センサダミーを確認する場合は、`ESP32書き込み` の `センサテスト近道` から目的のテストを選びます。
詳細は `docs/sensor_test_sketches.md` を参照してください。

光学式オドメトリをテストフィールドへ反映する場合は、`optical_odometry_test` を書き込み、`シリアル` タブで `OPTICAL_STATUS,OK` と `OPTICAL,dx,dy` が出ていることを確認します。`テストフィールド` タブの `光学式位置反映` がONなら、実データとして新しく受信したdx/dyだけR2位置へ加算されます。

## F3RC2026公式フィールド表示

`テストフィールド` タブでは、F3RC2026公式フィールド図面ベースのmm座標モデルを表示できます。

1. 表示モードを `公式フィールド表示` にします。
2. グリッド、ゾーン名、壁/木枠、ライン、ロボット軌跡、LiDARレイを必要に応じてON/OFFします。
3. マウスをフィールド上に置くと、左上原点のmm座標が表示されます。
4. 現在位置、角度、現在ゾーン、最近傍壁までの距離を確認します。

公式寸法は `config/field/f3rc2026_field.yaml` で管理しています。実フィールドでは±5%の寸法差があり得るため、最終調整では実測値で補正してください。

## テストフィールドの通常表示

`テストフィールド` タブでは、R1/R2、R2移動量、センサ状態、フィールド寸法を通常運用向けに確認できます。

- R1表示/R2表示を切り替え
- R2をR2スタートライン枠内に表示
- グリッド、ゾーン名、寸法、軌跡、LiDARレイを切り替え
- LiDAR未接続時は前/左/右/後すべて0 mm
- DUMMY受信時は状態をDUMMYと表示し、実センサ値欄は0として扱う
- `オブジェクト編集モード` で黒レンガ、白レンガ、じょうろなどを追加
- 追加したオブジェクトはドラッグ移動、複製、座標指定、移動量指定で調整可能
## 書き込みタブの使い方

`書き込み` タブでは、ESP32スケッチを選択、編集、検証、書き込みできます。

一番簡単な流れ:

1. ESP32をUSB接続する
2. `1 ESP32を探す` を押す
3. `9軸IMUテストを書き込む` または `通常制御を書き込む` を押す
4. 確認ダイアログで承認する
5. 書き込み後に `シリアルで確認` を押す

細かく操作する場合:

1. `書き込み` タブを開く
2. スケッチを選択する
3. コードを確認または編集する
4. `✓ 検証` を押す
5. `→ 書き込み` を押す
6. 確認ダイアログで承認する
7. 書き込み後に `シリアルで確認` を押し、`シリアル` タブで115200 bps接続して出力を見る

自動アップロードは行いません。実モータ出力も有効化しません。詳細は `docs/arduino_ide_tab.md` を参照してください。
