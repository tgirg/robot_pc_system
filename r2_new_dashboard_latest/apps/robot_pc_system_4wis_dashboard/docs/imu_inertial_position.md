# IMU慣性推定

9軸IMUテストスケッチの `ACC,ax,ay,az` と `IMU,yaw,pitch,roll` を使い、短時間の位置推定をテストフィールドへ反映します。

## 使い方

1. `書き込み` タブで `imu_9axis_test` をESP32へ書き込みます。
2. `シリアル` タブでESP32へ接続します。
3. `ACC,...`、`IMU_STATUS,OK`、`IMU,...` が出ていることを確認します。
4. `センサ` タブで `更新` を押します。
5. `IMU` タブで `accel x / accel y / accel z` が変化していることを確認します。
6. `センサ` タブの `IMU慣性推定を開始`、または `テストフィールド` の `IMU慣性推定開始` を押します。

## 注意

IMU加速度だけの位置推定は、静止時のノイズや姿勢誤差で必ずドリフトします。

この機能は短時間の確認用です。正確な自己位置推定には、光学式オドメトリ、エンコーダ、LiDAR、フィールド上の基準位置補正を組み合わせてください。

## 受信形式

```text
IMU_STATUS,OK
ACC,0.0123,-0.0045,0.9980
IMU,0.00,1.20,-0.50
GYRO,0.0100,0.0200,0.0300
```

`ACC` の単位は g です。PC側では `x/y` をフィールド座標へ回転し、速度と位置へ積分します。
