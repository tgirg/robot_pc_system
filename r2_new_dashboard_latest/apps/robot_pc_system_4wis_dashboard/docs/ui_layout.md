# UIレイアウト

## 新しい画面構成

ダッシュボードは、実機テスト中に重要な情報をすぐ確認できるように整理しています。

- 上部ヘッダー: 現在モード、安全状態、ESP32接続状態、現在指令、緊急停止
- 実機確認: ESP32、IMU、LiDAR、エンコーダ、モータ出力、現在指令を大きなカードで表示
- シミュレーション: 仮想フィールド、シミュレーション操作、自動走行、走行操作
- センサ詳細: 接続状態、センサ値の詳細、作業機構 / アクチュエータ
- ログ: ESP32受信ログ、操作ログ、診断ログ
- 設定 / 診断: ESP32通信テスト、環境診断、COMポート確認、カメラ確認

## 実機確認タブ

実機確認タブは、実機接続時に最初に見る画面です。

- ESP32接続カードで、接続中 / 未接続 / エラーを確認します。
- IMUカードで、IMU状態、yaw、pitch、roll、gyro x/y/zを確認します。
- LiDARカードで、前方、左、右、後方の距離を確認します。
- エンコーダカードで、左エンコーダ / 右エンコーダを確認します。
- モータ出力カードで、現在のモータ指令と安全ダミー状態を確認します。
- 現在指令カードで、PCから送った最後の走行指令を確認します。

## ダミー表示の意味

ダミー値は実センサ値ではありません。実機テスト時に誤解しないよう、カードにはデータ種別を表示します。

- ESP32ダミー出力: ESP32ファームウェアが接続確認用に出している固定値です。
- Mockデータ: PC側が実機なしで作っている確認用データです。
- シミュレーション: 仮想フィールド上の計算値です。
- 実データ: 接続された実センサからの値です。
- データなし: 受信できる実データがありません。

`IMU_STATUS,DUMMY` を受信した場合は `IMU状態：ESP32ダミー出力` として表示します。
`LIDAR_STATUS,DUMMY` を受信した場合は `LiDAR状態：ESP32ダミー出力` として表示します。
`MOTOR_DUMMY,left,right` を受信した場合は `モータ出力：無効（安全ダミー）` として表示します。

## ログタブ

ログタブでは、開発中に必要なログを分けて確認できます。

- ESP32受信ログ: `STATUS,OK`、`IMU,...`、`LIDAR,...`、`MOTOR_DUMMY,...` などの生データ
- 操作ログ: ボタン操作、指令送信、安全制限、エラー
- 診断ログ: 環境診断、COMポート確認、カメラ確認の実行履歴

`ログ消去` で画面上のログを消去できます。
`クリップボードへコピー` で3種類のログをまとめてコピーできます。

## シミュレーションモードと実機接続

シミュレーションモードでは、通常の走行操作ボタンはESP32へ実機指令を送りません。指令は安全レイヤーを通ったあと、仮想ロボットへ適用されます。

実機への送信確認は、`設定 / 診断` タブの `ESP32通信テスト` にある `テスト送信` を明示的に押した場合だけ行います。
# 現在の画面構成

現在のUIは、機能ごとに小さなページへ分割しています。

- ホーム: 大きな状態カードで全体を確認
- 実機接続: ESP32接続、実機クイック確認、接続前チェックリスト
- センサ: センサ概要、IMU、LiDAR、エンコーダ、カメラ
- 駆動: 走行操作、現在指令、モータ出力状態
- シミュレーション: 地図、ロボット位置、仮想LiDAR、自動走行
- ログ: ESP32受信ログ、操作ログ、診断ログ、実機確認結果
- 設定: ハードウェア構成、ローカル設定、保存先
- 診断: 環境診断、COMポート確認、カメラ確認、ESP32通信テスト
- ドキュメント: 関連資料を開くリンク

実機データとダミーデータを混同しないよう、各画面で「データ種別」を表示します。

詳細は `docs/ui_feature_split.md` を参照してください。
