# UIフィードバック改善メモ

## 目的

ダッシュボード上でボタンを押した直後に、処理中・成功・失敗が分かるようにしました。
ESP32書き込み、ファームウェア編集、シリアルモニタ、実機クイック確認のように時間がかかる操作では、状態ラベルや進行表示を使って現在の処理を表示します。

## 追加された表示

- 画面上部の最新通知に、直近の操作結果を表示
- 処理中のボタンは一時的に無効化し、文言を「接続中...」「保存中...」などに変更
- 長い処理では進行バーを表示
- 成功時は緑、失敗時は赤、処理中は青系の状態表示
- ファームウェア編集では未保存状態を色で表示
- 実機クイック確認では「確認中」「OK」「失敗」を項目ごとに表示

## 主な対象操作

- Arduino CLI確認
- ESP32スケッチのコンパイル
- ESP32への書き込み
- ファームウェア編集画面での読み込み、保存、コンパイル
- シリアルモニタのCOM更新、接続、切断、受信開始、送信、ログ保存、ESP32リセット
- 実機接続、接続テスト、実機クイック確認

## 注意

表示改善のみで、ESP32への自動書き込みや実モータ出力の有効化は行いません。
モータ出力は既存の安全設定を維持します。
