# 診断機能

## 目的

診断機能は、ダッシュボードからPC環境、COMポート、カメラ状態を確認するための補助機能です。
現在は `設定 / 診断` タブから実行できます。

## 設定 / 診断タブの使い方

ダッシュボードを起動し、上部タブから `設定 / 診断` を開きます。

表示されるボタン:

- `環境診断を実行`
- `COMポート確認`
- `カメラ確認`
- `全診断を実行`

結果は `診断結果` 欄に表示されます。この欄は選択してコピーできます。

## 環境診断

`環境診断を実行` は次を確認します。

- Pythonバージョン
- Python実行ファイル
- PySide6
- cv2
- serial
- numpy
- yaml

ライブラリが `NG` の場合は、次を実行してください。

```cmd
tools\setup_windows.bat
```

## COMポート確認

`COMポート確認` はpyserialを使って現在見えているCOMポートを表示します。

表示される情報:

- ポート名
- 説明
- hwid

ESP32のCOMポートを確認したら、必要に応じて `pc\config.yaml` の次を変更します。

```yaml
serial:
  port: "COM10"

communication:
  usb:
    port: "COM10"

controllers:
  drive:
    port: "COM10"
```

変更後はダッシュボードを再起動してください。

## カメラ確認

`カメラ確認` はカメラindex `0` から `3` を確認します。
確認後はカメラをreleaseし、開いたままにしません。

ダッシュボードがカメラを使用中の場合、環境によっては診断側で `未検出` と出ることがあります。
その場合でも、メイン画面のカメラ表示が動いていれば問題ありません。

## 全診断

`全診断を実行` は、環境診断、COMポート確認、カメラ確認をまとめて実行します。

診断は別スレッドで実行されるため、通常の画面更新や緊急停止ボタンを妨げない設計です。

## コマンドラインで実行する場合

UIを起動せずに診断する場合:

```cmd
.venv\Scripts\python.exe examples\run_diagnostics.py
```

または:

```cmd
.venv\Scripts\python.exe pc\diagnostics\diagnostics_report.py
```
