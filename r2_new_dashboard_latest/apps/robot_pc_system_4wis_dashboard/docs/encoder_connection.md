# エンコーダ接続メモ

## 目的
左右車輪の速度と距離を取得するためにエンコーダを使います。

## A相/B相
A相とB相の2本で回転方向とカウントを取得します。左右それぞれのピンを `config/hardware_profile.yaml` に記録します。

## 割り込み
ESP32ではGPIO割り込みでカウントする想定です。使用可能な割り込みピンを確認してください。

## プルアップとノイズ
必要に応じてプルアップ抵抗やノイズ対策を行います。長い配線はノイズを拾いやすくなります。

## 出力フォーマット
```text
ENC,left,right
```

## 変更する場所
- `esp32/drive_controller/drive_controller.ino`
- 将来追加するエンコーダ読み取りモジュール
- `pc/sensors/serial_sensor_parser.py`

## UIで見る項目
`実機確認` タブのエンコーダカードと、実機クイック確認の `エンコーダ受信` を確認します。
