# ESP32プログラム編集

## 目的

ダッシュボード内でESP32ファームウェアを直接編集するための機能です。Arduino IDEを開かなくても、`esp32/drive_controller/drive_controller.ino` などのコードを読み込み、編集、保存、コンパイル確認できます。

## drive_controller.inoの開き方

`診断` タブの `ESP32プログラム編集` を開くと、既定で次のファイルを読み込みます。

```text
esp32/drive_controller/drive_controller.ino
```

`読み込み` ボタンから `esp32/` フォルダ内の `.ino`、`.h`、`.cpp` なども開けます。安全のため、このエディタでは `esp32/` フォルダ外のファイルは編集できません。

## 保存方法

- `保存`: 現在のファイルへ上書き保存
- `名前を付けて保存`: `esp32/` フォルダ内に別名保存
- `Ctrl+S`: 保存
- `変更を破棄`: ファイルを再読み込み

編集は自由です。Arduino/C++コードをそのまま入力、貼り付けできます。自動整形や強制的な書き換えは行いません。

## バックアップ場所

既存ファイルを保存する前に、次の場所へバックアップを作成します。

```text
backups/firmware/
```

例:

```text
backups/firmware/drive_controller_20260708_174500.ino
```

バックアップ作成に失敗した場合は、そのまま保存するかキャンセルするかを確認します。

## コンパイル方法

`このコードをコンパイル` を押すと、未保存の変更がある場合は保存確認を行ってから、既存のArduino CLI設定でコンパイルします。

```cmd
arduino-cli compile --fqbn <FQBN> esp32\drive_controller
```

コンパイルだけを行い、ESP32へ自動書き込みはしません。

## 書き込み画面への移動

`書き込み画面へ移動` を押すと、診断タブ内の既存ESP32書き込み画面へ移動します。未保存の変更がある場合は保存確認を行います。移動しても自動書き込みは行いません。

## テンプレート

`テンプレート挿入` から次のコードを挿入できます。

- I2Cスキャナ
- 最小Serialテスト
- DRIVE VEL応答テスト
- IMU出力テスト
- LiDAR出力テスト
- 安全ダミーdrive_controller

`安全ダミーdrive_controller` は現在の内容を置き換えるテンプレートなので、挿入前に確認します。

## I2Cスキャナテンプレートの使い方

9軸IMUなどのI2Cアドレス確認に使います。ESP32のI2Cピンはテンプレート内で `Wire.begin(21, 22)` としています。実配線が違う場合は、SDA/SCLピン番号を変更してください。

## モータ未接続時の注意

現在モータが未接続でも、将来モータを接続したときにコードが動作する可能性があります。`analogWrite()`、`ledcWrite()`、`digitalWrite()`、`pinMode()` を含むコードは警告します。

## MOTOR_OUTPUT_ENABLED 1 の意味

`MOTOR_OUTPUT_ENABLED 1` は、実モータ出力を有効にする意図の設定です。モータ接続時は実際に動く可能性があります。エディタは保存を禁止しませんが、保存やコンパイル前に強い警告を表示します。

## 自由編集と自己確認

このエディタは自由編集できます。危険そうなコードもブロックしません。ただし、実機へ書き込む前にコード内容、配線、電源、モータ出力設定を必ず確認してください。

## 書き込み後の出力確認

書き込み後は `診断` タブの `シリアルモニタ` でESP32の生Serial出力を確認できます。I2Cスキャナや独自デバッグ出力の確認に使ってください。詳しくは `docs/serial_monitor.md` を参照してください。
