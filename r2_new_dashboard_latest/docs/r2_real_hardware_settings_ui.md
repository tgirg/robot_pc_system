# R2 実機接続・設定UI

新GUIの `実機接続・設定` タブは、R2の接続確認と、開発中に変更する設定をまとめて扱います。

## コントローラ確認

- 接続済み / 未接続
- pygameが認識したコントローラ名
- `vx`、`vy`、`omega` のリアルタイム入力
- ARM組合せボタンとSAFEボタンの押下状態

この確認画面は入力状態を表示するだけで、ARMやモータ出力は行いません。新GUIを出力無効で起動した場合も、生のコントローラ入力確認はできます。

## 編集できる設定

- FL / FR / RL / RRのサーボch
- FL / FR / RL / RRのモータphysical番号
- FL / FR / RL / RRのエンコーダphysical番号
- モータ、エンコーダ、サーボの個別反転
- 車体寸法、速度、PWM上限、整列・加減速パラメータ
- サーボ中心パルス、端点、角度範囲、トリム、最大速度、調整済み状態
- エンコーダCPR、モータPID、出力上限、フィードフォワード、開ループ始動PWM補償
- コントローラ軸、反転、デッドゾーン、入力倍率、ARM/SAFEボタン割当
- 機体の論理前方（`FRONT / RIGHT / REAR / LEFT`）。`REAR`は並進`vx / vy`を180°反転し、旋回`omega`は維持

## 保存と反映

1. R2をSAFE・出力停止にする。
2. 設定値を編集する。
3. `設定を保存して即時反映` を押す。
4. 確認画面で保存を確定する。
5. `保存・即時反映完了` を確認する。

保存時は `config/gui_backups/<日時>/` に現在の `vehicle_config.json` と `controller_mapping.json` を退避します。GUIタイマーを一時停止し、DISARMを送信してから新しいCONFIGをESP32へ送り、`config_ack` を確認します。成功後もSAFE・出力停止を維持し、再起動は不要です。

ARM中、ESP32未接続、CONFIG拒否、または応答タイムアウト時は反映しません。PC上の設定ファイルを保存前のバックアップへ戻し、実行中の設定も以前の内容へ戻します。失敗後はSAFEを維持し、接続状態を確認してから再度保存します。

現段階の新GUIは初回走行安全上限としてPWMを120以下に制限します。高出力化は実機の方向、サーボ角、エンコーダ方向、停止操作を確認した後に別の安全マイルストーンとして扱います。

現在のR2は機体前後を入れ替えて運用するため、`config/controller_mapping.json`の`logical_front`を`REAR`にしています。個別のモータ・サーボ反転とは独立した車体座標変換です。

`開ループ始動PWM補償を使用`を有効にすると、非ゼロのPWM指令を各輪の`ff_static_pwm_pos / neg`からPWM上限まで線形補間します。0指令は0のままです。現在値は浮上実測に基づきFL=40、FR=25、RL=30、RR=40です。PIDは引き続き無効で、接地・荷重下の速度一致を保証するものではありません。
